# JustNatur Shopify Theme

Premium Online Store 2.0 theme for JustNatur.

## Upload to Shopify

1. Download **`justnatur-theme-shopify-upload.zip`** from this repo (click the file → Download), **or**
2. Click green **Code → Download ZIP**, then upload that zip to Shopify.

Shopify needs `layout/theme.liquid` at the **root** of the zip (this repo is structured that way now).

**Shopify Admin → Online Store → Themes → Add theme → Upload zip file**

## After upload

1. Create products: Kesha Combo (tag `combo`), Kesha Mula, Kesha Amrith Hair Oil
2. Create pages and assign templates: About, Science, Ingredients, FAQ, Contact, Combo, Reviews
3. Set menus (`main-menu`, `footer`) and theme settings (featured products, colors)
